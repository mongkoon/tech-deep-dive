# 현대 프로그래밍 언어의 패러다임 및 기능 크기 비교

> 키워드: `#ProgrammingLanguages` `#Swift` `#Kotlin` `#TypeScript` `#Python` `#JavaScript` `#Rust` `#Cpp`

---

## Q1. Swift(100%) 대비 Kotlin, TypeScript, Python, JavaScript의 기능 크기는?

| 언어 | Swift 대비 기능 크기 | 핵심 차이점 요약 |
| :--- | :---: | :--- |
| **Swift** | **100% (기준)** | 메모리 관리(ARC), 값/참조 타입, 프로토콜, 엄격한 동시성(`Actor`), 매크로 등 최상위 복잡도 |
| **Kotlin** | **약 85 ~ 90%** | Swift와 가장 비슷한 체급. JVM 기반이라 메모리 관리·값 타입 개념이 빠져 약간 더 가벼움 |
| **TypeScript** | **약 80 ~ 85%** | 런타임 기능은 매우 작지만, **타입 시스템만 떼어놓으면 Swift보다 방대하고 복잡함** |
| **Python** | **약 55 ~ 65%** | 메모리·접근 제어·타입 규칙이 단순해 핵심 문법이 절반 수준으로 간결함 |
| **JavaScript** | **약 45 ~ 55%** | 익혀야 할 공식 기능 개수는 가장 적음. 단, 언어 특유의 예외 동작(Quirks) 파악이 별도로 필요 |

## Q2. 현존 주요 프로그래밍 언어 14종의 기능 크기 및 패러다임 순위

| 순위 | 언어 | 기능 크기 (Swift=100%) | 주요 패러다임 및 크기 결정 요인 |
| :---: | :--- | :---: | :--- |
| **1** | **C++** | **140 ~ 150%** | 절차·객체·제네릭·함수형 통합. 수동 메모리, 템플릿 메타프로그래밍, 이동 시맨틱, 다중 상속 |
| **2** | **Rust** | **120 ~ 130%** | 소유권·빌림·라이프타임 모델, 트레이트, 매크로, `unsafe`, 정교한 비동기(`Pin`, `Send`) |
| **3** | **Scala** | **115 ~ 125%** | OOP + 고차 함수형 프로그래밍(고계 타입, 임플리싯, 패턴 매칭)을 JVM 위에 결합 |
| **4** | **C#** | **105 ~ 115%** | LINQ, 값/참조 타입, `Span<T>` 저수준 메모리 제어, 패턴 매칭, 동적 타입 |
| **5** | **Swift** | **100% (기준)** | 프로토콜 지향, 값 타입(`struct`/`enum`), ARC 메모리 관리, 엄격한 동시성(`Actor`), 매크로 |
| **6** | **Kotlin** | **85 ~ 90%** | Swift와 유사하나 GC 기반으로 메모리 관리 규칙이 빠지고, 코루틴·스코프 함수·JVM 상호운용성 포함 |
| **7** | **TypeScript** | **80 ~ 85%** | 런타임은 JS로 작지만, 조건부·매핑 타입 등 **타입 레벨 프로그래밍** 영역이 매우 방대함 |
| **8** | **Java** | **75 ~ 80%** | 전통적 OOP 중심. 레코드·패턴 매칭·가상 스레드가 추가되었으나 값 타입·프로퍼티 등이 없어 단출함 |
| **9** | **Dart** | **65 ~ 70%** | 건전한 Null 안전성, 믹스인(Mixin), Isolate 동시성, 스트림 등 UI 개발에 최적화된 중형 크기 |
| **10** | **Python** | **55 ~ 65%** | 동적 타이핑, GC, 데코레이터, 제너레이터, 매직 메서드 등 간결한 핵심 문법 |
| **11** | **JavaScript** | **45 ~ 55%** | 클로저, 프로토타입/클래스, `Promise`, 이벤트 루프 중심의 작은 공식 스펙 |
| **12** | **Go (Golang)** | **35 ~ 40%** | 상속·예외·클래스 등을 의도적으로 제거한 미니멀 설계. 고루틴과 채널 중심 |
| **13** | **C** | **30 ~ 35%** | 키워드 40여 개 수준의 초소형 문법. 추상화 기능 없이 하드웨어·포인터를 직접 제어 |
| **14** | **Lua / Scheme** | **15 ~ 25%** | 임베디드·함수형 극단적 미니멀 언어 (Lua는 키워드 21개, 핵심 자료구조 1개) |
